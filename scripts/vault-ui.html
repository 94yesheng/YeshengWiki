保险箱生成器

把访问令牌加密成一份密文，写进站点上的数据文件。之后打开后台只需要输账号和密码。
这个页面只在本机跑（127.0.0.1）—— 令牌与口令不会离开这台电脑，也不会被部署到站点上。

要加密的东西

GitHub 的细粒度令牌：只授权本仓库、只给 Contents 读写、建议 90 天有效期。
口令强度：账号和密码合起来算 —— 长短比字符种类更重要。
生成前会先用同一口令自检一遍（解一遍看能不能解回令牌）—— 免得手滑打错密码、 产出一份连你自己也解不开的密文。

注意事项

  • 口令没有找回途径。忘了就重跑这个页面生成一份新的（密文本来就是可替换的）。
  • 账号别用站名、昵称、拼音缩写这类能被猜到的词 —— 那样它就退化成"盐"，不提供额外强度。
  • 密文会随站点公开（任何人能下载），所以口令强度就是唯一的防线：最好是一句 4–5 个不相关词的短语。
  • 换令牌或换口令 = 再生成一次 + 提交推送；顺手在 GitHub 上撤销旧令牌。
