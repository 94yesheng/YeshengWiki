# 照片目录

照片**图片本体**放在这里。构建时 Astro 会自动生成多档尺寸并转成 WebP，不需要手工压缩。

## 重要：元数据不在这里

照片的标题、时间、地点、记录文字，以及"哪几张照片属于同一面墙"，都存在
**`src/content/photos/` 下的数据文件里**（一面墙一个 json）—— 不在这里，也不在文件名里。

格式见 `src/content/photos/README.md`。

> 早先的版本是从**文件名**解析日期和说明（`2026-03-09-鸡煲.jpg` → 日期 + 说明），
> 后来改掉了：标题、地点、记录塞不进文件名，而且"一面墙可以只有一张、也可以有很多张"
> 这个分组关系必须显式记录下来。原因写在 `src/content.config.ts` 的 `photoWalls` 注释里。

## 放在这里的文件

- 支持 `jpg` / `jpeg` / `png` / `webp` / `avif`
- 建议保留日期前缀（`2026-03-09-鸡煲.jpg`）：**文件名已不承载语义**，但带日期在文件夹里
  排序看着清楚，而且从 WordPress 迁移过来的旧图不用改名
- 竖构图的照片在网格里用 3:4 而不是 4:3，避免把画面裁坏（判断逻辑在 `src/utils/photos.ts`）
- 上传和替换通常由后台完成，一般不需要手动往这里丢文件
