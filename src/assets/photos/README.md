# 照片目录

把图片直接放进这个文件夹，构建时会自动出现在照片页，并按日期分组。

## 命名约定

文件名以日期开头（必需），说明可选：

```
2026-03-09-鸡煲.jpg      日期 2026-03-09，说明「鸡煲」
2026-03-09.jpg           日期 2026-03-09，无说明
鸡煲.jpg                  无日期，会排在照片页最后
```

支持 jpg / jpeg / png / webp / avif。

## 不用手工处理图片

构建时 Astro 会自动生成多档尺寸并转成 WebP，
手机和桌面各取所需，不需要你自己压缩。

竖构图的照片会自动用 3:4 而非 4:3，避免把画面裁坏。
